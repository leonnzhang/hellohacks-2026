    Privacy & data

    Where your information goes.

    ⌂

    Saved in this browser

    Memories and your API key stay in this Chrome profile. There is no Relay account or server database.

    ✦

    Automatic saving is optional

    When enabled, visible chats from ChatGPT, Claude, and Gemini are sent to OpenAI to find lasting facts. These may include allergies or accessibility needs you mention.

    ↗

    You control sending

    The extension adds context to your first message in the destination chat. You choose when to send it.

    Semantic search

    Off. Saved conversations and memories stay out of the search index.

    When enabled, saved text is sent to OpenAI to create embeddings. The searchable text and vectors stay in this browser. Embeddings are also sent for each retrieval query. Use the OpenAI API key below; charges may apply. Turning this off clears the local search index.

    Automatic saving

    Off

    No key saved.

    Relay checks each new chat turn after the assistant replies. It saves only lasting facts you explicitly state. API charges may apply; you can edit or delete memories anytime.
